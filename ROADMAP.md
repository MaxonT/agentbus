# Roadmap

The basic direction. Not a dated plan.

- One gate for every agent's commands and tools, so the same rules hold whichever agent runs.
- Apps that any agent can use, built on the public API.
- Standing instructions an agent can set up from chat, such as a review before changes are applied.
- Context made visible, and kept small.
- More machines and more runners, so work spreads across them.

## Where help is welcome

- **More harnesses.** OpenCode and the Gemini CLI are the first candidates. See the open issues.
- **More model routes.** Local OpenAI-compatible endpoints (Ollama, LM Studio) and more OpenRouter models, so an
  agent can run on whatever a person already has.
- **More model formats.** An OpenAI Chat Completions adapter, so local and OpenAI-compatible vendors are recorded and
  priced like the rest.
- **Prices that stay current.** Tooling to show where the built-in price table drifts from a public source.
- **Good first issues, kept stocked.** Small, self-contained tasks with a starting point in the code.

Ideas and requests: open an issue.
